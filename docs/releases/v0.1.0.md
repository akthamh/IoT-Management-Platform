# v0.1.0 — Python CLI Foundation

## Objective

Build the first working version of the IoT Management Platform using only Python concepts 
## concepts

```text
Functions
Modules
Imports
Lists
Dictionaries
Loops
Conditions
Input
Validation
```

## Included

- CLI menu
- Python modules
- device catalog
- device categories
- manual device registration
- temporary in-memory storage
- list devices
- search devices
- input validation

## Manual test

Start:

```powershell
python main.py
```

Test:

1. Open device catalog.
2. Add a Temperature Sensor.
3. Add an ESP32.
4. List devices.
5. Search by device name.
6. Search by serial number.
7. Try invalid menu values.
8. Exit and restart the program.
9. Confirm that devices are gone after restart.

Step 9 demonstrates why the next version needs a database.
