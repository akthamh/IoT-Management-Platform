# v0.2.0 — SQLite Device Persistence

## Objective

Replace temporary in-memory device storage with persistent SQLite storage using Python's built-in `sqlite3` module.

## Learning goals

- SQLite databases
- SQL tables and primary keys
- unique serial numbers
- database connections
- parameterized SQL queries
- CRUD operations
- Python modules
- persistent data

```
CLI input
   ↓
device_manager.py
   ↓

   ↓
database.py
   ↓

```

## Safety and validation

- SQL values use placeholders instead of string concatenation.
- Serial numbers are normalized to uppercase.
- Duplicate serial numbers are rejected.
- Device IDs must be positive integers.
- Deletion requires typing `DELETE` exactly.
- The runtime database is excluded from Git.

## Manual test checklist

1. Start the program with `python main.py`.
2. Add two devices with different serial numbers.
3. Close and restart the program.
4. Confirm that both devices remain available.
5. Search by device name.
6. Search by serial number.
7. Try to add a duplicate serial number and confirm that it is rejected.
8. Update a device name, optional field, type, and status.
9. Restart and confirm that the updated values remain available.
10. Start deletion and cancel it.
11. Delete a device by typing `DELETE` exactly.
12. Confirm that the deleted device is no longer listed.
